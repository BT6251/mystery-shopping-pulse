# Mystery Shopping Pulse

Touchpoint experience dashboard (demo data). Open the site link on laptop or phone.
Uploaded files stay in the uploader's browser and are never sent to this site.

Ask AI: free on-device model (WebLLM, Llama 3.2 3B; runs in the browser, no key) or an Anthropic API key.
`web-llm.js` is the WebLLM 0.2.85 browser bundle (Apache-2.0).
